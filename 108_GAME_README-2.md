# 108 --- README / Полное ТЗ для ИИ

## 1. Назначение документа

Этот документ является единым техническим и визуальным заданием для ИИ,
который должен помочь создать браузерную карточную игру «108».

Используй этот README как главный источник требований. Не придумывай
новые игровые правила, не меняй механику карт и не упрощай описанные
ниже правила без отдельного указания.

В качестве визуального референса используется предоставленное
изображение игрового стола: вертикальный мобильный интерфейс карточной
игры с зелёным игровым сукном, деревянным столом, четырьмя/несколькими
позициями игроков по периметру, крупными картами в центре, рукой игрока
внизу, стопкой добора, очками игроков и декоративной атмосферой чайного
стола.

Цель --- создать полноценную современную браузерную игру «108», которая
визуально выглядит как реальная настольная карточная игра премиального
уровня, но имеет удобный цифровой интерфейс.

------------------------------------------------------------------------

# 2. Название игры

Название:

**108**

Подзаголовок можно использовать:

**Карточная игра**

Основная идея бренда:

**108 --- больше, чем просто карты.**

Ключевые ассоциации:

-   стратегия;
-   тактика;
-   блеф;
-   риск;
-   скрытая информация;
-   штрафные цепочки;
-   борьба за очки;
-   выбывание при превышении 108.

------------------------------------------------------------------------

# 3. Главная цель игры

Игроки соревнуются в отдельных раундах.

Цель раунда:

**первым избавиться от всех карт.**

Цель всей партии:

**остаться последним активным игроком.**

Очки после каждого раунда суммируются.

Если игрок получает больше 108 очков, он выбывает.

------------------------------------------------------------------------

# 4. Колода

Используется колода из 36 карт.

Есть четыре масти:

-   ♠ Пики
-   ♥ Червы
-   ♦ Бубны
-   ♣ Крести

Есть девять значений:

-   6
-   7
-   8
-   9
-   10
-   Валет
-   Дама
-   Король
-   Туз

Итого:

**4 масти × 9 значений = 36 карт.**

------------------------------------------------------------------------

# 5. Количество игроков

Поддерживается:

**2--6 игроков.**

На первом этапе максимальное количество игроков:

**6.**

------------------------------------------------------------------------

# 6. Раздача

Обычный раунд:

**каждому игроку выдаётся 4 карты.**

Если перед началом нового раунда осталось только 2 активных игрока:

**каждому из двух игроков выдаётся 6 карт.**

Остальные карты формируют колоду добора.

------------------------------------------------------------------------

# 7. Первый раунд

В самом первом раунде первый игрок определяется:

**случайно.**

После определения первого игрока открывается стартовая карта из колоды.

Стартовая карта может сразу активировать своё специальное действие.

------------------------------------------------------------------------

# 8. Стартовая карта

Если первой открылась:

## 6

Игрок, который должен был начать, берёт:

**1 карту.**

После этого ход переходит следующему игроку.

## 7

Начинающий игрок берёт:

**2 карты.**

После этого ход переходит следующему игроку.

## 8

Начинающий игрок должен обработать 8 по специальным правилам восьмёрки.

## Туз

Начинающий игрок:

**пропускает ход.**

Ход переходит следующему игроку.

## Дама

Дама просто находится сверху.

Начинающий игрок должен перебить её по обычным правилам либо
использовать другую даму.

## Король пик

Начинающий игрок берёт:

**5 карт.**

После этого ход переходит следующему игроку.

------------------------------------------------------------------------

# 9. Обычная карта

В обычном состоянии игрок может сыграть карту, если она совпадает с
верхней картой:

1.  по масти;
2.  по значению.

Например, если сверху:

**♥9**

разрешены:

-   ♥6
-   ♥7
-   ♥8
-   ♥9
-   ♥10
-   ♥В
-   ♥Д
-   ♥К
-   ♥Т
-   любая другая 9 любой масти
-   любая дама

------------------------------------------------------------------------

# 10. Дама

Дама --- универсальная карта.

Она может перебить:

**любую карту.**

После того как игрок кладёт даму, он сразу выбирает любую масть.

Например:

**♠9 → Q**

Игрок выбирает:

**♥**

Следующий игрок должен играть по ♥ либо использовать даму.

Выбранная масть должна визуально отображаться на столе.

Пример интерфейса:

**Заявлена масть: ♥**

Важно:

Игрок выбирает масть именно после выкладывания дамы.

------------------------------------------------------------------------

# 11. Туз

Туз пропускает следующего игрока.

Например:

**♣Т**

Следующий игрок не делает ход.

После пропуска ход переходит следующему активному игроку.

Туз можно продолжать играть:

**Т → Т → Т**

Каждый новый туз снова пропускает следующего игрока.

------------------------------------------------------------------------

# 12. Шестёрка

6 является штрафной картой.

Первая 6 создаёт штраф:

**+1 карта.**

Следующий игрок может вместо получения штрафа положить любую 6.

Масть не имеет значения.

Пример:

**6 → +1**

**6 → 6 → +2**

**6 → 6 → 6 → +3**

**6 → 6 → 6 → 6 → +4**

Цепочка продолжается, пока игроки продолжают выкладывать шестёрки.

6 можно перебить:

**только 6.**

7 не перебивает 6.

Обычная карта не перебивает 6.

------------------------------------------------------------------------

# 13. Семёрка

7 является штрафной картой.

Одна 7 создаёт:

**+2 карты.**

Следующий игрок может положить любую 7, независимо от масти.

Пример:

**7 → +2**

**7 → 7 → +4**

**7 → 7 → 7 → +6**

**7 → 7 → 7 → 7 → +8**

7 можно перебить:

**только 7.**

6 не перебивает 7.

Обычная карта не перебивает 7.

------------------------------------------------------------------------

# 14. Восьмёрка --- уникальная механика игры

8 является специальной картой, вокруг которой строится скрытая механика
добора и блефа.

Если сверху лежит:

**♠8**

игрок должен найти карту, которой можно продолжить игру по правилам
восьмёрки.

Главное условие --- **масть текущей восьмёрки.**

В примере с:

**♠8**

игроку нужна:

**♠ карта.**

------------------------------------------------------------------------

# 15. Если подходящая карта уже есть в руке

Если у игрока есть пиковая карта:

**♠9**

он может сыграть её:

**♠8 → ♠9**

После этого ход переходит следующему игроку.

------------------------------------------------------------------------

# 16. Если подходящей карты нет

Если игрок не имеет карты нужной масти, он начинает брать карты из
колоды.

Важное отличие от обычного добора:

**при 8 игрок может брать сколько угодно карт.**

Он не обязан останавливаться на первой подходящей карте.

------------------------------------------------------------------------

# 17. Скрытый добор и блеф

Карты, которые игрок вытягивает во время специального добора 8, не
должны быть видны другим игрокам.

Это намеренная игровая механика.

Игрок может вытянуть подходящую карту и продолжить добор, скрывая от
остальных, что подходящая карта уже у него есть.

Например:

На столе:

**♠8**

Игрок не имеет пик.

Он вытягивает:

**♥8**

Он может не показывать её и продолжить добор.

Затем получает:

**♦9**

Продолжает.

Затем:

**♠6**

Продолжает.

Затем:

**♠K**

Продолжает.

Игрок может остановиться и выбрать наиболее выгодную подходящую карту.

------------------------------------------------------------------------

# 18. Выбор карты после скрытого добора

Игрок сам выбирает:

**любую подходящую накопленную карту.**

Он не обязан играть последнюю вытянутую карту.

Например, накоплены:

-   ♠6
-   ♠K
-   ♠10

Игрок выбирает:

**♠K**

и выкладывает её.

Следующий игрок получает эффект короля пик:

**+5 карт.**

Остальные игроки не должны знать, какие карты игрок вытягивал до выбора.

------------------------------------------------------------------------

# 19. Если во время добора выпала 8

Это особая ситуация.

Например:

На столе:

**♠8**

Игрок начинает скрытый добор.

Он вытягивает:

**♥8**

Игрок может скрыть её и продолжить добор.

Если он в итоге выбирает:

**♥8**

она выкладывается.

Теперь действует уже:

**♥8**

И игрок должен продолжить перебивать эту новую восьмёрку по её масти.

Например:

**♠8 → ♥8 → ♥10**

После ♥10 ход переходит следующему игроку.

Если игрок выбирает другую подходящую карту вместо ♥8, цепочка новой
восьмёрки не возникает.

------------------------------------------------------------------------

# 20. Пример сложной цепочки 8

Исходная карта:

**♠8**

Игрок не имеет пик.

Во время скрытого добора получает:

-   ♥8
-   ♦8
-   ♠6
-   ♠K

Игрок решает сыграть:

**♥8**

Теперь он должен перебить:

**♥8**

Он получает возможность использовать карту ♥.

Допустим, играет:

**♥10**

После этого ход переходит следующему игроку.

------------------------------------------------------------------------

# 21. Если колода закончилась во время добора 8

Если карты в колоде закончились, игрок прекращает добор.

Он обязан использовать подходящую карту из уже имеющихся у него карт.

При этом учитываются карты, которые он накопил во время текущего
скрытого добора.

Если подходящей карты нет вообще, необходимо предусмотреть серверную
защиту от невозможного состояния. В обычной корректно работающей игре
такое состояние должно быть обработано правилами переработки сброса или
отдельным серверным сценарием, если он будет добавлен позднее.

Не придумывать новое правило без согласования.

------------------------------------------------------------------------

# 22. Король пик

**♠K** --- специальная штрафная карта.

После её выкладывания следующий игрок получает:

**+5 карт.**

После получения штрафа его ход заканчивается.

Другой король не отменяет штраф.

------------------------------------------------------------------------

# 23. Последняя карта

Если игрок выкладывает последнюю карту из руки, он сразу заканчивает
раунд.

Специальный эффект последней карты при этом сохраняется.

Примеры:

## Последняя карта --- 6

Игрок выигрывает раунд.

Следующий игрок получает соответствующий штраф, если игровой порядок
требует его применения.

## Последняя карта --- 7

Игрок выигрывает раунд.

Следующий игрок получает соответствующий штраф.

## Последняя карта --- 8

Игрок выигрывает раунд.

Раунд заканчивается.

## Последняя карта --- Туз

Игрок выигрывает раунд.

Следующий игрок должен был бы пропустить ход.

## Последняя карта --- ♠K

Игрок выигрывает раунд.

Следующий игрок получает +5 карт.

## Последняя карта --- Дама

Игрок выигрывает раунд и получает бонус за окончание дамой.

------------------------------------------------------------------------

# 24. Подсчёт очков

После завершения раунда победитель получает:

**0 очков**, если последняя карта не была дамой.

Остальные игроки считают стоимость всех оставшихся карт.

  Карта      Стоимость
  -------- -----------
  Валет              2
  Дама               3
  Король             4
  6                  6
  7                  7
  8                  8
  9                  9
  10                10
  Туз               11

Пример:

Остались:

**В + Q + 8 + Т**

Сумма:

**2 + 3 + 8 + 11 = 24**

24 добавляется к накопленному счёту игрока.

------------------------------------------------------------------------

# 25. Бонус за окончание дамой

Если игрок закончил раунд дамой:

**−20 очков.**

Если последняя карта:

**Q♠**

то:

**−40 очков.**

Бонус вычитается из накопленного счёта.

Счёт может быть отрицательным.

Пример:

**10 − 20 = −10**

------------------------------------------------------------------------

# 26. Система 108

После завершения каждого раунда пересчитывается накопленный счёт.

## Если счёт меньше 107

Игрок продолжает игру.

## Если счёт равен 107

Счёт изменяется:

**107 → 53**

## Если счёт равен 108

Счёт изменяется:

**108 → 0**

## Если счёт больше 108

Игрок выбывает.

Например:

**104 + 7 = 111**

Игрок выбывает.

------------------------------------------------------------------------

# 27. Начало следующего раунда

После подсчёта очков определяется игрок с самым большим текущим
количеством очков среди активных игроков.

Но он НЕ начинает новый раунд.

Начинает:

**следующий активный игрок по часовой стрелке после игрока с
максимальным счётом.**

Пример:

Позиции по часовой стрелке:

1.  Игрок 1 --- 5 очков
2.  Игрок 2 --- 9 очков
3.  Игрок 3 --- 2 очка
4.  Игрок 4 --- 7 очков

Максимальный счёт:

**Игрок 2 --- 9.**

Следующий по часовой стрелке:

**Игрок 3.**

Следовательно, следующий раунд начинает:

**Игрок 3.**

------------------------------------------------------------------------

# 28. Если игрок с максимальным счётом вылетел

Если игрок с максимальным счётом получил больше 108 и вылетел, он
исключается из определения следующего игрока.

Берётся следующий максимальный счёт среди активных игроков.

После него по часовой стрелке определяется первый игрок нового раунда.

------------------------------------------------------------------------

# 29. Два последних игрока

Когда после выбывания остаются только два активных игрока:

**в следующем раунде каждому выдаётся по 6 карт.**

Игра продолжается между двумя игроками.

После выбывания одного из них второй становится победителем всей партии.

------------------------------------------------------------------------

# 30. Визуальная концепция

Основной визуальный стиль:

**премиальная современная карточная игра на реальном деревянном столе.**

Основные материалы:

-   натуральное дерево;
-   зелёное карточное сукно;
-   тёмный металл;
-   матовое золото;
-   кожа;
-   бумага;
-   керамика;
-   стекло.

Атмосфера:

-   тёплая;
-   уютная;
-   дорогая;
-   реалистичная;
-   немного восточная;
-   вечерняя;
-   домашняя;
-   атмосферная.

Не использовать кислотный неон как основной стиль.

Не делать интерфейс похожим на дешёвую мобильную казино-игру.

------------------------------------------------------------------------

# 31. Игровой стол

Центральная часть интерфейса:

**круглый или овальный зелёный игровой стол.**

Вокруг:

-   деревянная поверхность;
-   декоративные элементы;
-   чай;
-   орехи;
-   посуда;
-   локальные атмосферные предметы;
-   мягкое тёплое освещение.

Зелёное сукно должно занимать основную игровую площадь.

------------------------------------------------------------------------

# 32. Расположение игроков

Для 6 игроков:

-   один игрок снизу;
-   один снизу слева;
-   один сверху слева;
-   один сверху;
-   один сверху справа;
-   один снизу справа.

Каждый игрок имеет:

-   аватар;
-   имя;
-   количество карт;
-   текущий счёт;
-   индикатор активности;
-   визуальный индикатор хода.

Не нужно показывать лицевую сторону чужих карт.

Показывать только рубашки карт и количество.

------------------------------------------------------------------------

# 33. Игрок пользователя

Игрок пользователя находится снизу.

Его карты отображаются веером.

Карты должны быть:

-   достаточно крупными;
-   читаемыми;
-   немного перекрывающими друг друга;
-   расположенными симметрично;
-   с возможностью выбора;
-   с подсветкой допустимых карт.

Количество карт должно быть очевидно.

Не допускать визуального перекрытия, из-за которого нельзя определить,
сколько карт находится в руке.

------------------------------------------------------------------------

# 34. Центр стола

В центре находится зона сброса.

Карты должны лежать:

-   плоско;
-   в одной перспективе;
-   без чрезмерного 3D;
-   с небольшим естественным перекрытием;
-   лицевой стороной вверх.

Последняя сыгранная карта должна быть визуально выделена.

------------------------------------------------------------------------

# 35. Колода добора

Колода находится рядом с центральной зоной.

Она отображается:

-   плоской стопкой;
-   рубашкой вверх;
-   с небольшой толщиной;
-   без огромного 3D-наклона.

Количество карт можно отображать небольшим числом рядом с колодой.

------------------------------------------------------------------------

# 36. Индикатор хода

В центре или рядом с игроком отображать:

**Ход: Вы**

или:

**Ход: Адам**

Активный игрок должен визуально выделяться.

Можно использовать:

-   мягкое золотое свечение;
-   тонкую рамку;
-   небольшую анимацию;
-   подсветку аватара.

Не использовать раздражающее мигание.

------------------------------------------------------------------------

# 37. Индикатор масти

После дамы обязательно показывать выбранную масть.

Например:

**Масть: ♥**

Или визуальный крупный символ:

**♥**

Индикатор должен быть хорошо заметен до следующего изменения масти.

------------------------------------------------------------------------

# 38. Индикатор штрафа

Если активна цепочка 6:

**Штраф: +3 карты**

Если активна цепочка 7:

**Штраф: +6 карт**

Если действует король пик:

**Штраф: +5 карт**

Информация должна быть понятна без чтения правил.

------------------------------------------------------------------------

# 39. Верхняя панель

В верхней части:

-   кнопка меню;
-   номер раунда;
-   таймер;

# 48. Главный принцип безопасности

Сервер является единственным источником истины.

Нельзя доверять браузеру следующие данные:

-   разрешённость карты;

-   выбывание.

Браузер отправляет только намерение:

Сервер проверяет, можно ли это сделать.

# 49. Защита скрытой механики 8

Это критически важно.

Когда игрок находится в режиме добора 8:

Другие игроки не получают:

-   вытянутые карты;
-   порядок вытянутых карт;
-   подходящие карты;
-   скрытые карты игрока.

Только сам игрок видит свои накопленные карты.

После завершения выбора сервер раскрывает только сыгранную карту.

Например, остальные видят:

**Игрок сыграл ♠K.**

Они не видят:

**Игрок до этого вытянул ♥8, ♦9 и ♠6.**

# 61. Особый UX для 8

Во время скрытого добора игрок должен видеть:

**Текущая масть: ♠**

**Вы вытягиваете карты, пока не решите остановиться.**

Накопленные карты видит только он.

После получения подходящих карт появляется:

**Выберите карту для игры**

Игрок может выбрать любую подходящую накопленную карту.

Кнопка:

**Продолжить добор**

позволяет продолжить поиск.

Кнопка:

**Остановиться**

завершает поиск.

После остановки игрок выбирает карту.

# 62. Основная игровая философия

«108» должна ощущаться не как простая игра на совпадение карт.

Главные элементы:

**Тактика**

Игрок решает, когда использовать сильные карты.

**Риск**

Нужно следить за накопленными очками.

**Блеф**

Особенно во время добора 8.

**Контроль штрафов**

6, 7 и ♠K позволяют передавать проблемы следующему игроку.

**Управление рукой**

Иногда выгоднее сохранить карту.

**108**

Игроку необходимо контролировать накопительный счёт.

для скрытого добора и блефа → останься последним.**
